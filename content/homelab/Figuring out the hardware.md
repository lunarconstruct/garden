# big gay nas v1
the hardware went through so many different iterations before landing on what we've got now.
started off with a raspberry pi zero 2 w - a tiny little thing with like. 0 ram and no processing power at all. it was only 15$ tho lmao
![raspberry pi zero 2 w | 400](https://assets.raspberrypi.com/static/f03a00485ac096c1033ad1c4a530d63b/15dad/zero2-close-up.webp)
this thing SUCKED lmfao it was good for hosting like, one application and thats it. which was fine at first since i just wanted to do navidrome. but as the plans grew and grew it became very obvious that this wasn't going to cut it.
i moved up to a raspberry pi 3b+
![400](https://vilros.com/cdn/shop/files/main_0c2ddd65-ae41-4863-aea4-d0d66dd63565.jpg?v=1713192998)
this one was a little better. it had a whopping ONE GIGABYTE of ram !! this was enough to host the navidrome server as well as maybe jellyfin? but it was slowww about it. and at this point, i was getting really into it and was getting ideas for other things i wanted to host (minecraft server???) so 1gb wasn't going to cut it either.
next i went to a raspberry pi 4.
![400](https://assets.raspberrypi.com/static/raspberry-pi-4-labelled-f5e5dcdf6a34223235f83261fa42d1e8.png)
get this - 4gb of ram. and then that still wasn't enough so i returned it and got one with 8gb of ram. which was probably fine for hosting all my applications but not enough for a minecraft server,,, we had started the minecraft server on here but it was soooo laggy. hard to get anything done with only 2gb of [dedotated wam](https://www.youtube.com/watch?v=wsO-Td0hqXo).
we stuck with this iteration for a bit though! enough for my awesome friend [[Najah]] to engineer, design, and print a custom case for me!!
